# Machines that build themselves. The deck's half of the self-building loop.
#
# Outside creative mode, placing a deck machine puts down a GHOST: the machine stands there, covers
# its tiles, and is made of nothing. It does not run, it does not hold pressure, and it weighs
# nothing. It gives itself one opening -- a construction port on its centre tile -- and fills itself
# off whatever passes over it, exactly as a drawn run of track does. When it holds its whole bill it
# is simply a machine.
#
# What to read in the shots:
#   `placed`  -- a gauge collar in faint slate on the run: a plan, not an instrument;
#   `grown`   -- the same collar in full colour, paid for out of the tank;
#   `marked`  -- the same collar framed in warm orange, on its way out.
#
# ⚠️ **A GAUGE, and that is not an arbitrary choice.** The purity rule is asked of every species in a
# machine's bill against its own share of the recipe, so a thing made of an alloy cannot be built out
# of one of its components. The starter vessel's tank holds iron, and of every deck machine in the
# game only the gauge and the bridge are made of iron -- a hull and an airlock are steel, a thermal
# furnace is firebrick, and everything else is titanium. Until something aboard can
# blend a storage to a recipe, those two are the only machines a starter vessel can build.
#
# The numbers:
#   builtMass    grams that stopped being cargo and became fabric -- rail AND casing both.
#                One tile of rail is 130,642 g; a gauge's casing is 261,284 g, two tiles' worth.
#   massBalance  extracted + baseline == aboard + vented + built. Zero throughout.

new
creative 0
camera centre 34 9 64

# Track first, and the machine after: nothing is auto-laid, so the player draws every length of it.
# Four tiles east of the tank's output port, fed by the tank.
brush RAIL
drag 32 9 35 9
run 1200
expect massBalance = 0

# A gauge onto the middle of that run. It arrives holding nothing.
brush GAUGE
place 34 9
probe 34 9
expect massBalance = 0
# The build menu covers half the view, so the shots are taken with it put away. INSPECT is what puts
# it away: it is the default tool and the one that changes nothing, so it cannot disturb what is
# being photographed. (It replaced WIRE, which is what this line used to say.)
tool INSPECT
shot placed

# ...and pays for itself out of the same tank the track did.
run 800
probe 34 9
expect massBalance = 0
shot grown

# Mark it. It goes warm rather than cold -- "not yet" and "on its way out" are opposite mistakes and
# must never look alike.
tool BUILD
remove 34 9 DECK
tool INSPECT
run 400
probe 34 9
shot marked

# ⛔ And here it stops, holding all 261,284 g of its casing.
#
# **A machine cannot hand its metal back while a lump is standing on its tile**, and a machine sits
# in the middle of a working line, so on any belt that is carrying anything the tile under it is
# occupied more or less always. The tank goes on pushing iron down the run, every tile stays loaded,
# and the gauge waits for a gap that never comes.
#
# This is the same occupied-tile deadlock `ghosts.txt` records for a marked rail, and the plan parks
# it as Stu's decision. Worth knowing that it is *much* easier to hit here: a rail has to be
# deliberately overfed, whereas a machine is normally on a line that is doing its job. `GhostTest`
# and `MachineGhostTest` prove deconstruction works when the metal has somewhere to go; this records
# what happens on a live belt.
run 1600
probe 34 9
expect massBalance = 0
