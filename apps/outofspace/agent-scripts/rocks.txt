# A rock exists — increment H1, restated in the world frame by H2a.
#
# What to read: the rock falls when it is over the deck, does NOT fall when it is out in open space,
# and slides astern when the engine lights even though nothing pushed it. That last one is the whole
# increment, and since H2a it is stated the honest way round: the rock's *velocity* is zero, because
# nothing touched it, and its *position on the grid* walks toward the stern because the ship left.
# `rockVX` is through the world; `rockX` is which tile it is over.
#
# `rockBalance` must stay 0. A rock is new mass in a closed world and the only thing keeping that
# honest is that `capturedGrams` admits every gram of it.
# `new 0`: an empty sky. A starting world scatters a field of rocks (H4), and this script
# plants and counts its own, so it asks for none.
new 0

# Deck plating, explicitly. A vessel has none since H1b — the only gravity in this game is thrust —
# and this half of the script is about the *other* half of the rule: the plating reaches a rock while
# it is over the deck. So the script has to switch it on to have anything to check.
gravity 0 1

echo --- one rock, dropped amidships
rock smelter smelter+8
expect rockCount = 1
expect rockGrams > 0
expect rockBalance = 0
# The ore ledger must not have noticed. A rock does NOT go through the miner -- the extractor exists
# to delete the miner, and hanging it off that ledger would weld the two together. See plan §5f.
#
# `massBalance` is the statement, not `extractedGrams`. Since H3 the two ledgers are hinged -- a rock
# is where ore comes from -- so what has to be true is that the ore balance still closes with
# sixty-three kilos of rock in the room, i.e. that a rock nobody has eaten yet is in neither of the
# terms. The rock's own ledger says the rest, and it is checked on its own line.
expect massBalance = 0

echo --- and it falls, because it is over the plating
run 6
expect rockVY > 0

echo --- three more, and the books still close
rock smelter-10 smelter+8
rock smelter-5 smelter+8
rock smelter+5 smelter+8
expect rockCount = 4
expect rockBalance = 0
expect airBalance = 0
expect heatBalance = 0
camera centre 18 14 22
shot rocks-falling

echo --- now with the plating off, and the engine lit
new 0
gravity 0 0
rock 18 smelter+20
run 1
expect rockVY = 0
expect rockVX = 0

# The ship leaves; the rock stays where it was and so appears to slide astern. Nothing pushed it.
#
# Caught at twenty ticks as well as at the end, and that is not padding. By sixty the rock is
# thirty-five tiles behind and off the grid entirely, which is the correct answer and a useless
# picture — the world view can only ever show the vessel's own frame. Twenty ticks is where you can
# still see it crossing the room.
thrust 1 0 20
# It was dropped centred on tile 18, so a centre still at 18.5 would mean it had kept station.
expect rockX < 18
expect rockVX = 0
camera centre 18 16 22
shot rocks-astern

thrust 1 0 40
expect positionX > 0
expect rockX < 10
expect rockVX = 0
expect rockBalance = 0
expect momentumBalance = 0
# By now it is off the grid, and the nav panel is the only thing that can still say where it is.
shot rocks-gone
