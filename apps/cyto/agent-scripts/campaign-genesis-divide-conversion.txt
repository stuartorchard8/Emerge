# ch00-genesis -> ch01-divide, end to end through the UI, taking the CONFLICTING fuel pair.
#
# The convert gene grows on REDOGEN (r) and the divide gene is fuelled by bonding r+g, so growth and
# division compete for the same atom -> ch01-divide branches to ch02-conversion.
#
# Every action here is the one the coach copy actually instructs. If a step's wording, gate or a gene-card
# label changes, this script stops passing — that is the point.

campaign ch00-genesis
expect chapter ch00-genesis
expect step 1/11

# 1. Look around.
camera pan 0.05 0.05
next
expect step 2/11

# 2. Place the first, geneless cell.
tap 0.35 0.5
expect cells 1
next

# 3. Select it, 3.5 open the chemistry readout.
select 0.35 0.5
next
tap-ui + CHEMISTRY
next
expect step 5/11

# 4. Drag it.
dragcell 0 0.4 0.55 20
next

# 5. Watch it starve. No genes means no way to rebuild, so it ruptures below 1000 biomass.
# 4000, not 3000: measured in the pocket world, the cell is at biomass 1003 on tick 3000 - three
# units above the rupture floor - and goes shortly after. The player just watches until it dies
# (the gate is a cell count, not a clock), so only this script needs the margin.
run 4000
expect cells 0
next

# 6. Place a fresh cell and select it — this one gets a genome.
tap 0.35 0.5
select 0.35 0.5
next
expect step 8/11

# 7. Author the first GROW gene: blank gene, then action, then chemical.
tap-ui + NEW GENE
expect genes 1
next
tap-ui NOTHING
tap-ui GROW
expect convertChem
next
tap-ui (NONE)
tap-ui +R
tap-ui close
expect convertChem r
next
expect step 11/11

# Segue into Divide — same world, same cell.
next
expect chapter ch01-divide
expect step 1/12

# 1-2. The dead end, then the DIVIDE gene.
next
tap-ui + NEW GENE
tap-ui NOTHING
tap-ui Divide
expect hasDivide true
next

# 3. It doesn't fire: the cell has outgrown what it can pay.
next

# 3.5. Cap growth — the first condition the player ever authors. ALWAYS drops in `CHEM (NONE) > 0`,
# and all three parts change. The sheet is modal, so close it before touching the card again.
tap-ui ALWAYS
tap-ui CHEM (NONE)
tap-ui BIO
tap-ui close
tap-ui >
tap-ui 0
tap-ui 0
type 3000
tap-ui SET VALUE
tap-ui close
expect growthCap 3000
next

# 4. Light is a trickle; division needs a lump sum. Switch the DIVIDE gene (the SECOND gene, hence @2)
# onto chemistry. Picking BOND opens the reaction sheet straight away; its default pair is r+g.
next
tap-ui USE LIGHT @2
tap-ui BOND
tap-ui close
expect bond rg
expect fuelConflicts true
next
expect step 9/12

# 5. It divides — and both daughters rupture on the spot. The step auto-advances on the die-off, so
# there is no Next to click here. A cell splits its biomass in two, so dividing
# under 2000 leaves each daughter below the 1000 rupture floor. The lineage wipes itself out.
# 4000, not 2000: measured in the pocket world, the founder is still growing toward its divide floor at
# tick 2000 and the die-off lands between 2000 and 4000. Nothing the player sees is on a clock.
run 4000
expect cells 0
expect step 10/12

# 6. Put the genome back in the world and select it, so the gene card is there to edit.
tap 0.35 0.5
select 0.35 0.5
expect cells 1
next
next
expect step 12/12

# 7. The fix: a BIO > 2000 floor on the DIVIDE gene. The blank clause ALWAYS drops in is already `> 0`,
# so only the left side and the number change. The DIVIDE gene is the only one still unconditional, so
# `ALWAYS` needs no @n here.
tap-ui ALWAYS
tap-ui CHEM (NONE)
tap-ui BIO
tap-ui close
tap-ui 0
tap-ui 0
type 2000
tap-ui SET VALUE
tap-ui close
expect divideFloor 2000
next

# 8. THE BRANCH. r+g eats the monomer GROW grows on, so this lineage gets the conversion chapter.
expect chapter ch02-conversion
